## 🕌 Islamic Patterns

```

  ✦   ✦
✦   ⬟   ✦
  ✦   ✦
    ⭐

```

║ ║ ║ ║ ║ ║
╚═╝ ╚═╝ ╚═╝

### Arabesque Flow
```
  ⟨⟩
 ⟨  ⟩
⟨    ⟩
 ⟨  ⟩
  ⟨⟩
```
**Usage**: Headers, footers, borders

## 🌟 Design Features

### ✨ Animations
- **Hover Effects**: Cards lift on hover with shadow
- **Loading States**: Spinning Islamic star pattern
- **Transitions**: Smooth 300ms transitions
- **Float Effect**: Subtle floating animation on icons
- **Glow Effect**: Pulsing glow on active elements

### 🎯 Typography
- **Headings**: Bold, large (text-3xl, text-2xl, text-xl)
- **Body Text**: Regular, readable (text-base, text-sm)
- **Arabic Text**: Amiri font (font-arabic class)
- **Monospace**: For code/data (font-mono)

### 📐 Spacing System
- **Cards**: p-6 padding (24px)
- **Sections**: space-y-8 vertical spacing (32px)
- **Grid Gaps**: gap-6 (24px)
- **Page Padding**: p-8 (32px)

### 🔵 Border Radius
- **Cards**: rounded-2xl (16px)
- **Buttons**: rounded-xl (12px)
- **Inputs**: rounded-lg (8px)
- **Badges**: rounded-full (9999px)
